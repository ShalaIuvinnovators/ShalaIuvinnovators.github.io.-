The problem, as the market has it

Most companies run on a dozen tools that don't talk to each other, and the AI agents everyone is bolting on can only see the one tab they live in. The suite most of the working world still runs on has not changed shape in thirty years, and everyone who uses it knows it.

The fix Macro is building

One system: email, chat, docs, tasks, calls, a customer list and agents in a single fast window, where anything can be linked to anything else and the agents share one memory across all of it. Macro has run its own company on it for two years. The bet is simple: one shared system beats eleven integrations, and an agent that can see everything is the first one worth trusting with real work.

The whole product is open source, every service, readable today at github.com/macro-inc/macro, about 4,700 stars. Rust underneath, a SolidJS client, local first, CRDTs. Not open core.
