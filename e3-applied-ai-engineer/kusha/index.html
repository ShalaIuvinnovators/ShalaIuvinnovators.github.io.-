The role

A full-stack applied AI engineer seat: hands-on, customer facing, and built around agents. Most of your time goes into building LLM agents and the evaluation loop that proves them before they ship, along with the APIs behind them and the React dashboard customers work in.

It is not an infrastructure or platform seat. The systems and research team owns the models and the machinery underneath; you take what they build and put it in front of customers.

The company

E3 Group is a seed-stage applied AI lab for freight and supply chain, started by an MIT and Stanford pair. Its products already run for paying customers: Shield verifies about 5,000 drivers a day against fraud, Frontline runs voice agents for about a tenth of what rivals charge, and workflow and document ingestion is next. The team is small and flat, and everyone is a member of technical staff.

The work

The models already work. What this seat is about is proving an agent is right before a customer leans on it.

So you build the agents, and you build the loop that tests them against the real production workflow: cases pulled from real failures, checks on every tool call and state change, a pass line, and a release that does not ship until it clears. When a judge model scores the output, you check that judge against human labels. The results land on a React dashboard you build, with the API and the data behind it, where the customer and the team can see what passed.

Who this seat is for

You have shipped an agent and you can say plainly how you knew it was right. Insiders call it the release gate: the golden set and regression suite that decide what ships.

React is part of the job and it is required, but you do not need to be a front-end expert. A working dashboard you shipped is enough. The depth E3 looks for is in building and testing agents, and that is where the technical rounds go.

Where your work meets this seat

At Raft you build AI agents for freight forwarding, so the domain is already yours. On Starithm, your own live product, you put LLM verification, Bayesian false-alarm filtering and confidence scoring between the model and the person reading the answer, and you built the front end in React and Vite.

That is this loop. Here it becomes the release gate on agents that freight customers run every day, with the pay in dollars.

What you would own

The agents on a customer surface, start to finish, and the verification loop that lets them ship: the cases, the thresholds, the dashboard that shows what passed. It is hands-on: you write and ship the code, with coding agents alongside you.

With the founders next to you, the way you test becomes the way the next product is tested, and that is where equity compounds.
